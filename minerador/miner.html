Minerador real (não é simulação): hashing SHA-256 duplo do protocolo Bitcoin, rodando no seu celular, submetendo shares via proxy Stratum.

Realidade estatística: mesmo otimizado, o hashrate de um celular contra a dificuldade da rede (casa dos 1014) torna a chance de achar um bloco sozinho praticamente zero. O campo "tempo médio p/ bloco" mostra isso em números. É mineração solo de verdade — só que estatisticamente inviável em pequena escala.

Como funciona / otimizações aplicadas

Midstate: os primeiros 64 bytes do cabeçalho (versão, hash anterior, início da merkle root) não mudam quando o nonce muda. Eles são comprimidos uma vez por job em vez de a cada tentativa — isso elimina 1 das 3 compressões SHA-256 por hash.

Zero alocação: todos os buffers (cabeçalho, estado, agenda de mensagens) são criados uma vez e reaproveitados. A versão anterior criava ~12 objetos por tentativa, sufocando o coletor de lixo.

Rejeição rápida: a palavra mais significativa do hash descarta 99,99% dos candidatos com uma única comparação de inteiro, sem montar nem inverter o hash de 32 bytes.

WebAssembly: o mesmo algoritmo compilado de C para WASM, com volta automática para JavaScript se o navegador não suportar. O indicador "motor" no topo mostra qual está ativo.

Navegadores não abrem conexão TCP bruta, por isso a página fala com o proxy Stratum/WebSocket (Node.js) que roda no seu PC.
